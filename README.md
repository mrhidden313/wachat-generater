# wachat-generater

A realistic, pixel-perfect WhatsApp Review Chat Generator designed for high-converting customer reviews.

## Features
- **Android / MIUI Dark Mode Replica:** Pixel-perfect recreation of WhatsApp dark theme interface.
- **Top-to-Down Message Sequencing:** Supports custom client and business chat bubbles with realistic tails and timestamps.
- **Continuous HD Wallpaper:** Seamless WhatsApp dark wallpaper (`wa chat.jpg`) extending through the entire viewport.
- **Real WhatsApp Vector Assets:** Flat encryption lock, native outline emoji, 45° tilted attachment paperclip, camera, and voice note mic icons.
- **HD Image Export:** Built-in 1-click 3x retina PNG download (`html2canvas`) and browser print support.

## Usage
Simply open `index.html` in any modern web browser or serve locally:
1. Configure phone number, subtitle, status bar time, and battery level.
2. Specify the number of client and business messages.
3. Type message texts and adjust timestamps.
4. Click **Print Result** to preview the exact WhatsApp screenshot.
5. Click **Download HD PNG** or take a native screenshot.
